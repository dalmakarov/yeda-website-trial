# Yeda responsive website prototype

Unpublished static prototype that joins the redesigned Yeda pages into one local project.

## Routes

- `/` — Home
- `/programs/` — Programs and FAQ
- `/about/` — About
- `/team/` — Team and profile dialogs
- `/contact/` — Contact and booking handoff
- `/first-lesson-us/` — First Lesson

## Local preview

From `prototype/dist` run a static web server and open its local address. The current review server uses port `4173`.

## Safety state

- The prototype has not been published.
- Every page includes `noindex, nofollow`.
- Existing canonical and hreflang values point to the current public URLs.
- Current page titles, descriptions, structured organization data, prices, offer details, policies, and FAQ answers are retained.
- Wix Bookings and Wix form workflows must be reconnected inside Wix before any approved publication.

See `CONTENT_REVIEW.md` for confirmed content discrepancies that need an owner decision.
